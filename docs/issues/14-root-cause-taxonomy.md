# Issue #14: 根因分类体系

> Parent: 期6 改进清单（grill Q2：封闭枚举 + 其他桶；每类绑定三件确定性资产）

## What to build

- **封闭枚举根因类别**（6-8 个初稿）：需求理解偏差 / 越权改动 / 测试验证缺失 / 工具能力缺口 / 风格约定不符 / 环境上下文缺失 + 「其他」桶
- 每个类别绑定三件资产（数据驱动配置，可改词表不调代码）：
  1. 验证检查项清单（供 #15 静态确认）
  2. skills 搜索词（供 #16 推荐物搜索）
  3. 推荐物类型路由（hook / skill / MCP）
- **LLM 根因分类器**：headless 调用（复用 review.ts runCli），输入已确认信号 + 上下文，LLM 只做选择题不做创作；分不进的进「其他」
- 分类结果落库（信号 → 根因类别 + 分类置信度），手动触发（此票先做引擎与 API，UI 按钮在 #16）

## Acceptance criteria

- [x] 类别配置数据驱动（改配置即可增删类别/调整资产）
- [x] 假 LLM 注入时分类结果落库；LLM 返回非法类别时归入「其他」
- [x] 同一批信号重复分类幂等（不产生重复记录）
- [x] 测试覆盖分类容错与「其他」桶
